# Folio

Folio is a small installable reading app: well-developed ideas from history, psychology, and literature, each leading to the books and papers behind it.

It is a static site — HTML, CSS, and JavaScript, with no build step. Ideas, topics, and reading paths live in [`data/cards.json`](data/cards.json). Full texts that can be read inside the app live in [`texts/`](texts/), one file per work. GitHub Pages publishes these files as they are.
